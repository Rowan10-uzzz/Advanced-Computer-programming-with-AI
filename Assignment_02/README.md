# Assignment 02 — CampusWheels

This project models a small campus vehicle-rental desk using Python Object-Oriented Programming.

## Files

- `rental.py` — contains the `Vehicle`, `Renter`, `ElectricCar`, and `Motorbike` classes
- `main.py` — demonstrates renting, returning, validation, inheritance, and polymorphism
- `README.md` — project instructions

## How to run

Open a terminal in the `Assignment_02` folder and run:

```bash
python main.py
```

## OOP concepts demonstrated

- Classes and objects
- Encapsulation with `@property`
- Inheritance
- Polymorphism
